# English judging workspace release

## What changed

- The English routes now reuse the complete Korean product UI, preserving layout and behavior while translating interface copy.
- Parallel permit research is reachable from the same venue screen, with English summaries and links to retrieved sources. Unsupported fields remain unconfirmed.
- English catalogue, screenplay matching, location details, camera and lighting controls, permit research and personal activity are available. Venue text is translated for display; Korean source records and links remain unchanged for traceability.
- README reduced to the actual product, setup, deployment and limitations. Removed obsolete floor-plan UI and ADK runtime claims.
- Fixed `.gitignore` accidentally excluding `apps/web/src/lib`, so a checkout includes API and local persistence code.
- Secrets, local catalogue/cache, browser artifacts and build state are excluded from Git. The audited public release also excludes internal evaluation results, assistant handoff notes, and design PDFs.
